Politique de Confidentialité / Privacy Policy

1. Introduction

LOCK-IN est une application de productivité développée par NME. Nous respectons votre vie privée et nous engageons à protéger vos données personnelles. Cette politique explique quelles données nous collectons et comment nous les utilisons.

2. Données collectées

LOCK-IN collecte les données suivantes :

  • Adresse email : utilisée pour la création et l'authentification de votre compte via Firebase Authentication.
  • Données d'utilisation : durée des sessions, streaks, badges débloqués. Ces données sont stockées localement sur votre appareil et synchronisées via Firebase Firestore.

LOCK-IN ne collecte aucune donnée sur les applications que vous utilisez. Le blocage d'apps est géré entièrement par le framework Screen Time d'Apple, et nous n'avons pas accès à ces informations.

3. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Vous authentifier dans l'application
  • Synchroniser vos statistiques entre vos appareils
  • Permettre le fonctionnement du classement entre utilisateurs

4. Stockage et sécurité

Vos données sont stockées de manière sécurisée via les services Firebase de Google, conformes aux normes de sécurité industrielles. L'identifiant de votre tag NFC est stocké uniquement sur votre appareil et n'est jamais transmis à nos serveurs.

5. Partage des données

Nous ne vendons, n'échangeons ni ne transférons vos données personnelles à des tiers. Les seuls services tiers utilisés sont les services Firebase de Google pour l'authentification et le stockage de données.

6. Vos droits

Vous pouvez à tout moment :

  • Supprimer votre compte et toutes vos données en nous contactant
  • Réinitialiser vos données locales depuis les paramètres de l'application
  • Demander une copie de vos données

7. Contact

Pour toute question concernant cette politique de confidentialité, contactez-nous à : contact@nme-lockin.com
