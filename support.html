Questions fréquentes

Comment fonctionne le blocage d'apps ?

LOCK-IN utilise le framework Screen Time d'Apple pour bloquer les apps de ton choix. Une fois le lock activé, seul ton tag NFC peut débloquer tes apps.

Quel tag NFC utiliser ?

N'importe quel tag NFC compatible (NFC Forum Type 1-5, ISO 14443, ISO 15693). Tu peux en trouver facilement en ligne pour quelques euros. Au premier scan, LOCK-IN enregistre ton tag.

Que se passe-t-il si je perds mon tag NFC ?

Tu peux utiliser la procédure d'urgence (disponible 1 fois par jour, après 1h de lock). Tu peux aussi réinitialiser ton tag dans les paramètres.

Mes données sont-elles sécurisées ?

Oui. Tes données sont stockées via Firebase (Google) avec chiffrement. Nous n'avons aucun accès aux apps que tu utilises.
